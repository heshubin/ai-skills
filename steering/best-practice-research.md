# 最佳实践研究规则

## 核心原则

每个功能模块在实现前，必须先搜索业内最佳实践，综合出一套最优方案再动手。

## 执行流程

1. **搜索阶段** — 用 web search 搜索 2-3 个相关关键词组合：
   - 搜索同类产品（Slack Bot、Teams Bot、Discord Bot、飞书机器人）的实现方式
   - 搜索开源项目的实现参考
   - 搜索官方文档的推荐做法

2. **综合阶段** — 从搜索结果中提取：
   - 各平台的共性设计模式（说明这是行业共识）
   - 各平台的差异化亮点（可以借鉴的创新点）
   - 已知的坑和反模式（避免踩坑）

3. **落地阶段** — 结合项目实际情况，选择最适合的方案：
   - 不盲目照搬，要考虑企业微信 API 的限制
   - 不过度设计，要考虑当前项目的复杂度
   - 保持向后兼容，不破坏已有功能

## 适用场景

以下场景必须执行最佳实践研究：
- 新增功能模块（如群聊支持、日志查询、告警分析）
- 架构改造（如单 Agent → 多 Agent）
- 性能优化（如并发控制、缓存策略）
- 安全加固（如权限控制、输入校验）

## 不适用场景

以下场景可以跳过：
- 简单 bug 修复
- 配置项调整
- 文档更新
- 测试用例补充
