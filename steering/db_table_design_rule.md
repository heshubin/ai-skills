# 数据库设计规则

## 1. 主键设计

| 规则 | 说明 |
|------|------|
| 自增主键 | 所有表使用自增整型主键 |
| 主键命名 | 统一使用 `rec_id`，少数表可使用业务含义主键如 `{entity}_id` |
| 主键类型 | 统一使用 `bigint unsigned` |

## 2. 时间字段设计

| 规则 | 说明 |
|------|------|
| 秒级时间戳 | 新表统一使用 `bigint unsigned` 存储秒级 Unix 时间戳 |
| 毫秒级时间戳 | 需要毫秒精度时使用 `bigint` |
| 禁止 datetime | 新表不使用 `datetime` 类型（CDC 字段 `proguard_time` 除外） |
| 创建/修改时间 | 统一使用 `in_dtm` + `edit_dtm` 命名 |

## 3. 审计字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `in_user` | `varchar(50)` 或 `bigint` | 创建人（存用户名或用户ID均可） |
| `in_dtm` | `bigint unsigned` | 创建时间（秒级时间戳） |
| `edit_user` | `varchar(50)` 或 `bigint` | 修改人（与 in_user 保持一致） |
| `edit_dtm` | `bigint unsigned` | 修改时间（秒级时间戳） |

所有业务表必须包含以上四个审计字段。

## 4. 状态字段设计

| 规则 | 说明 |
|------|------|
| 数值型状态 | 新表使用 `tinyint`，定义明确的枚举值 |
| 禁止字符状态 | 新表不使用 `char(1)` 存储状态或布尔值 |

## 5. 命名规范

| 规则 | 说明 |
|------|------|
| 表名前缀 | 按业务模块加前缀，如 `{module}_` |
| 字段命名 | 全小写 + 下划线分隔（snake_case） |
| 关联字段 | 使用 `{entity}_id` 格式 |
| 日志表 | 后缀 `_log` |
| 归档表 | 按年份后缀，如 `_{year}` |

## 6. 数据类型选择

| 场景 | 类型 |
|------|------|
| 金额（常规） | `decimal(10,2)` |
| 金额（高精度，如汇率/利息） | `decimal(18,4)` |
| ID 引用 | `bigint` |
| 短文本 | `varchar(50)` ~ `varchar(255)` |
| 长文本 | `text` / `mediumtext` |
| 布尔/开关 | `tinyint` |
| JSON 数据 | `json`（谨慎使用） |
| 评分/比率 | `decimal(10,2)` |

## 7. 索引设计

| 规则 | 说明 |
|------|------|
| 主键索引 | 自增主键自带 |
| 业务唯一索引 | 关键业务字段设唯一索引 |
| 关联字段索引 | 外键关联字段建 `MUL` 索引 |
| 时间索引 | `in_dtm`、`edit_dtm`、`proguard_time` 按需建索引 |
| 状态索引 | 状态字段按需建索引 |
| 无外键约束 | 不使用数据库层面的 `FOREIGN KEY`，关联关系由应用层维护 |

## 8. 表设计模式

| 模式 | 说明 |
|------|------|
| 主表 + 扩展表 | 核心字段放主表，低频/大字段放扩展表 |
| 主表 + 日志表 | 变更记录写入独立的 `_log` 表 |
| 按年份分表 | 大数据量表按年份水平拆分 |
| 按业务域分库 | 不同业务模块使用独立数据库 |

## 9. 默认值规范

| 规则 | 说明 |
|------|------|
| 数值字段 | 默认 `0` |
| 字符串字段 | `varchar` 默认 `''`（空串），`text` 类型不设默认值 |
| 状态字段 | 必须有明确默认值 |
| 金额字段 | 默认 `0.00` |

## 10. 表级规范

| 规则 | 说明 |
|------|------|
| 存储引擎 | 统一使用 `InnoDB` |
| 字符集 | 统一使用 `utf8mb4`，排序规则 `utf8mb4_general_ci` |
| 业务编号字段 | 除自增 ID 外，可设独立的业务编号字段（`varchar`） |
| 冗余字段 | 为查询性能可适当冗余存储关联数据 |
| 字段不允许 NULL | 所有字段设置 `NOT NULL` + 默认值 |
| 表注释 | 所有表必须添加 `COMMENT`，说明表的业务用途 |
| 字段注释 | 所有字段必须添加 `COMMENT`，说明字段含义 |

## 新表设计 Checklist

- [ ] 主键：`rec_id bigint unsigned AUTO_INCREMENT`
- [ ] 引擎 `InnoDB`，字符集 `utf8mb4`
- [ ] 审计字段：`in_user` + `in_dtm` + `edit_user` + `edit_dtm`
- [ ] 时间字段使用 `bigint unsigned`（秒级时间戳）
- [ ] 金额字段使用 `decimal(10,2)`，高精度场景使用 `decimal(18,4)`
- [ ] 状态字段使用 `tinyint`，定义明确的枚举值
- [ ] 关联字段命名 `{entity}_id`，建 `MUL` 索引
- [ ] 表名使用业务前缀 + snake_case
- [ ] 不使用数据库外键约束
- [ ] 所有字段 `NOT NULL` + 默认值
- [ ] 考虑是否需要 `proguard_time` 用于 CDC
- [ ] 大表考虑按年份分表策略
